# GreenLog - Smart Sustainable Logistics System

GreenLog is a full-stack web application designed to optimize delivery routes, manage vehicle performance, track carbon emissions, and support EV charging station management.

## 🔧 Tech Stack

- **Frontend:** React, JavaScript, CSS
- **Backend:** Node.js, Express
- **Database:** MySQL

---

## 🚀 Features

- Route optimization for logistics
- Real-time vehicle performance tracking
- Carbon emission reports
- EV charging station locator
